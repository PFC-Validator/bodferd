# Product

This standalone project describes a proposed THORChain confidential node relay. The current deliverable is a design document and an owner-private reading website, not a working submission service.

Readers: the project owner, future node operators, maintainers and protocol reviewers. Success: understand how public node authorization, separate signing/encryption keys, Tor submission and maintainer verification fit together, then inspect exact technical contracts.

The webpage is Read mode: a quiet technical document with clear navigation, a concise architecture overview, full protocol reference, sources, print layout and downloadable Markdown. No report upload, live registration, telemetry, external fonts, third-party scripts or invented implementation claims.

Scope: standalone Bodferd project. Future service/CLI code should live here. Host the reading site privately by default. The protocol service itself is intended to be Tor-only; this document website is not the service.

Brand commitment: Bodferð, with the P.F.C. tagline “Private Fortified Communications.” The requested identity draws on Norse strength and private conversation using original geometry, not existing organization logos. The mark must remain legible at small sizes and distinct from THORChain, Signal and PFC branding.
