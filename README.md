# Bodferð reading edition

Static GitHub Pages output of [PFC-Validator/bodferd](https://github.com/PFC-Validator/bodferd), built from merged `main` at source commit [`a159899005396dd667bac94d2cbab08fadd40963`](https://github.com/PFC-Validator/bodferd/commit/a159899005396dd667bac94d2cbab08fadd40963). This edition includes the plain-language delivery explanation and support for several responsible people per node.

Publish this branch (`gh-pages`) from its root directory. `.nojekyll` preserves generated HTML, assets and downloadable Markdown without Jekyll processing. Public reading URL: https://pfc-validator.github.io/bodferd/.

The project remains a protocol design draft; no relay or messaging implementation is deployed by this site. This branch contains only the reading edition; the referenced source commit contains the design and build tooling.
