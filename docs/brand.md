# Bodferð identity

Display name: **Bodferð**. ASCII project name: **Bodferd**.

Tagline: **Private Fortified Communications.** Its initials preserve P.F.C.; the acronym is not repeated as an extra badge. “Fortified” names the intended protection and verified identity, while the document remains explicit that the product is a design.

The small original vector emblem combines an angular conversation seal, a broad Norse hammer and two diamond communication nodes. Small copper cuts give the enclosure a carved character. Deep fjord green and copper distinguish it from blue circular chat marks and existing chain emblems. PFC enters through the wording, not a copied logo. No upstream artwork, scripts or external fonts are used.

Assets in `src/brand/`: `bodferd-mark.svg` (color), `bodferd-mark-mono.svg` (one color), `bodferd-lockup.svg` (standalone name/tagline) and `favicon.svg`. Built assets are copied to `dist/brand/`. The page uses live lettering for accessible responsive text; the SVG lockup uses the same serif family with fallbacks. The mark stays geometric, flat and readable; do not turn it into a photorealistic shield or substitute an upstream logo.

The 512 × 512 transparent hero emblem (`bodferd-emblem-512.png`) develops the same message/hammer idea with copper, deep-green enamel and restrained Norse interlace. It was produced with the built-in image-generation tool, then resized to the requested dimensions while preserving alpha. The exact generation prompt is recorded in `docs/brand-generation.txt` and embedded in the PNG. Use the SVG mark for small icons; use the expressive PNG for the larger hero placement.

The files are original project artwork under the repository MIT license. The design is intentionally distinct; no exhaustive trademark or worldwide similarity clearance is claimed. Branding does not imply endorsement by another project.
